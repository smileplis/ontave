# Ontave website

Static landing page and documentation. The framework runtime remains in the parent directory and is never imported into browser code.

```sh
npm ci
npm run build
npm run check
npm run dev
```

Run commands from this directory within the full repository; the build uses the parent package version and shared `examples/playground` markup/assets. The build renders Markdown documentation and a React story island. GSAP drives the open source-to-record visualization and motion. Reduced-motion and short-viewport modes use explicit chapter controls. The output is dist/ with no server, database, key or runtime worker requirement. `/playground/` is an explicitly labelled guided sandbox that replays fictional reference runs generated by the real SDK and PostgreSQL. It never performs model inference or accepts arbitrary input. The separate CLI playground runs real SDK/database operations locally.

`src/benchmarks.mjs` contains published aggregates from the alpha.2 local synthetic runs disclosed in the benchmarks guide. The build exports those aggregates as `/benchmarks.json`; interactive SVG charts use the same data, with full methodology in the benchmarks guide. `src/expressive.css` provides the artwork layout. `src/refined.css` defines the reactive grid, full-screen product story and documentation workspace. `src/light.css` supplies the shared light palette and loads after the playground stylesheet. The site uses self-hosted DM Sans, a softened Noon hero, translucent navigation and a Farmhouse in Provence footer. `src/interaction.ts` draws nearby grid cells on pointer movement; reduced-motion users receive explicit chapter controls without the grid animation. These numbers do not claim semantic accuracy or human productivity.

The atomic logo and wordmark use the owner-supplied option 2 artwork from Google Drive (logo `1zMKa97keQjfy6dj6_8ggAoT7Dk9igFXv`, white variant `1Ee4_yYVpg1SQ_3tcJ39Vgsr5Xq8G9aZB`, wordmark `15cdOH84ECVgi1k938vhP090FBAjBha7C`). Original vectors are retained in public assets; `ontave-wordmark.svg` combines the original white atomic geometry with the original wordmark with a dark filter on the light surfaces.

Vercel project settings: root directory website, framework Other, build command npm run build, output dist. Node.js 24. Do not add any framework provider keys or database secrets to the static website project.

DM Sans regular and medium are self-hosted under the SIL Open Font License, included in `public/fonts/OFL.txt`. The owner-supplied Van Gogh images are compressed as WebP in `public/art/`; the 97 MB farmhouse source is not served. `public/ontave-display.svg` extracts the existing path-based wordmark for the oversized footer, so it stays sharp at every size. The canonical production address is `https://ontave.daltn.tech`; the existing `app.daltn.tech` alias remains usable.

The landing-page narrative follows promise → benefits → walkthrough → product boundaries → measured results → first session. Copy is adapted from the existing app.daltn.tech site to the concise, product-led cadence of the supplied Wafer reference. Technical qualification boundaries, benchmark disclosures and the fictional nature of examples remain explicit. Both public hostnames serve this same site.
