# Ontave website

Static landing page and documentation. The framework runtime remains in the parent directory and is never imported into browser code.

```sh
npm ci
npm run build
npm run check
npm run dev
```

Run commands from this directory within the full repository; the build uses the parent package version and shared `examples/playground` markup/assets. The build renders Markdown documentation and a React story island. UI primitives come from shadcn/ui; GSAP drives the scroll story and motion. Reduced-motion and short-viewport modes use explicit chapter controls. The output is dist/ with no server, database, key or runtime worker requirement. `/playground/` is an explicitly labelled guided sandbox that replays fictional reference runs generated by the real SDK and PostgreSQL. It never performs model inference or accepts arbitrary input. The separate CLI playground runs real SDK/database operations locally.

`src/benchmarks.mjs` contains published aggregates from the alpha.2 local synthetic runs disclosed in the benchmarks guide. The build exports those aggregates as `/benchmarks.json`; interactive SVG charts and their accessible table use the same data. `src/expressive.css` defines the public site’s warm-white, solid magenta and acid-yellow visual system; reduced-motion users receive the same content with explicit chapter controls. These numbers do not claim semantic accuracy or human productivity.

The atomic logo and wordmark use the owner-supplied option 2 artwork from Google Drive (logo `1zMKa97keQjfy6dj6_8ggAoT7Dk9igFXv`, white variant `1Ee4_yYVpg1SQ_3tcJ39Vgsr5Xq8G9aZB`, wordmark `15cdOH84ECVgi1k938vhP090FBAjBha7C`). Original vectors are retained in public assets; `ontave-wordmark.svg` combines the original white atomic geometry with the original wordmark recolored for the dark background.

Vercel project settings: root directory website, framework Other, build command npm run build, output dist. Node.js 24. Do not add any framework provider keys or database secrets to the static website project.

The requested Sets Grotesk family is used when installed locally; no commercial font file is redistributed. The public fallback is Helvetica Neue/Helvetica/Arial. A licensed webfont kit can be added when supplied by the owner.
