## Ontave developer preview

The public npm developer preview is **`0.1.0-alpha.5`**. Install it with `npm install ontave`, or run the [local playground](/docs/quickstart/) without an application setup. Earlier versioned GitHub archives remain available. No general production-readiness or arbitrary-data accuracy claim has been established.

## Available in the developer preview

- Immutable evidence, scoped authorization and fenced durable workers with append-only attempt accounting.
- Real process-kill/restart, bounded shutdown, lost-acknowledgement retries and repeated-crash budget checks.
- Whole-bundle review, authority-scoped identity decisions, corrections and replay respecting withdrawals.
- Additive candidates, isolated extraction/identity/relationship/observation/read evaluation, and atomic activation/replay scheduling.
- Pinned contracts, typed queries, bounded links, signed cursors and actual CLI workflows.
- Operator restore checks across all 18 tables, clean Node/Next.js package consumers and workspace-scoped metrics.

The complete solar/rental lifecycle demonstrations use a deterministic fictional adapter. They establish database behavior, rather than autonomous discovery accuracy.

The hosted browser sandbox and published benchmark figures retain their disclosed alpha.2 reference fixtures. The local npm command installs alpha.5. Those versions describe different artifacts.

## Try the preview

The [browser sandbox](/playground/) explores fictional SDK reference runs. The [one-command local playground](/docs/quickstart/) runs real SDK calls against temporary PostgreSQL, with a fixture adapter and no provider key. You can approve or decline the model, confirm identity matches, accept or reject the interpretation, and inspect the resulting record. Neither is a live-model accuracy demonstration.

## Qualification still open

The 60-input maintainer dataset has 179 expected field assertions and 107 relationship checks. Its labels have not been independently reviewed. Twenty executable read tasks are available; they are not an independently authored held-out set.

Live Gemini and Mistral experiments now have recorded precision/recall and failure results. Earlier configurations failed the 95% precision / 90% recall targets. Every experiment is retained, including incomplete runs. New schema or scoring policies produce separately frozen trials. A new three-trial `ministral-14b-2512` profile met the aggregate field targets: 97.7–97.8% precision and 96.1–97.2% recall. It used an explicit revised description-equivalence rule, frozen before fresh collection. It is a development result on the same maintainer dataset, not independent complete-MVP certification. Each trial still rejected one invented year-zero date. See [measurements and benefits](/docs/benchmarks/).

Independent source-label review, independently authored holdout cases, live established-identity linking, discovery and reviewed publication qualification remain open. Five acceptance cases are still partial, including complete experimental-provider input token profiling. An independent first-time setup walkthrough remains pending; automated clean installs are tested separately.

Public npm distribution uses a separate developer-preview release profile with implementation, recovery, consumer, security and exact-revision CI checks. It does not claim that the full MVP quality gates passed. The [packaged alpha.5 release status](https://github.com/smileplis/ontave/blob/v0.1.0-alpha.5/docs/RELEASE_STATUS.json) records those open gates.

## Deliberate boundaries

Alpha.5 adds a persistent local database, loopback review Studio and explicit bounded policy-authorized adoption of additive concepts and reported facts. Unsupported cases stay pending. These additions do not establish general autonomous-discovery accuracy.

The alpha does not implement physical business DDL, destructive model changes, automatic established-entity merges, a hosted database service, browser/edge runtime, React hooks or MCP integration.
